# Security

## Report a vulnerability

Use [private vulnerability reporting](https://github.com/ashwingopalsamy/atomberg-console/security/advisories/new).
Please do not open a public issue. Expect a reply within a week.

## What this app holds

An Atomberg API key and refresh token, in your macOS Keychain. Nothing else is sensitive. See
[docs/PRIVACY.md](docs/PRIVACY.md) for everything it stores and every address it contacts.

## Supported versions

The latest release.
