# Code of conduct

Be kind, be direct, assume good faith. Critique the code, not the person.

Harassment, personal attacks and discrimination are not welcome, and will get comments removed and people
blocked. Report problems privately through the address on the maintainer's GitHub profile.

This is the short form of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
