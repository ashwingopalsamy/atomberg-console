# Support

- Question or bug → [open an issue](https://github.com/ashwingopalsamy/atomberg-console/issues/new/choose).
  Include the version (About) and the last lines of `calls.log` for call-count questions.
- Problem with the Atomberg API itself → [Atomberg's developer documentation](https://developer.atomberg-iot.com).
- This is an unofficial hobby project. It is not supported by Atomberg.
